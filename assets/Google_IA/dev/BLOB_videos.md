pero como es la mejor forma de bajar un blob
La mejor forma y la más efectiva para bajar un video blob: es usando una extensión de navegador.
Un enlace blob: no es una dirección web real de un archivo, sino un marcador temporal que el navegador crea en su memoria para reproducir un video de forma segura. Por eso, si intentás copiar y pegar ese enlace en otra pestaña o en un programa externo, te va a dar error.
Las herramientas que mejor funcionan para "capturar" el video desde la memoria del navegador y guardarlo en tu computadora o celular son las siguientes:
1. La forma más recomendada: Extensiones de navegador
Estas extensiones analizan el reproductor de la página mientras el video se ejecuta y unen los fragmentos automáticamente.
FetchV (Video Downloader): Es actualmente una de las mejores para Chrome, Brave y Edge. Está diseñada específicamente para videos blob: y M3U8. Te permite grabar el flujo de datos directamente de la pestaña y descargarlo como MP4.
Video DownloadHelper: Es un clásico disponible para Firefox y Chrome. Detecta el video apenas le das play en la página web original y te permite descargarlo en un clic.
2. El truco técnico: Inspeccionar el código (Sin instalar nada)
A veces, detrás de un enlace blob: se esconde un archivo .m3u8 o .mp4 real que podés extraer vos mismo:
Entrá a la página web donde está el video.
Presioná F12 (o clic derecho y Inspeccionar) para abrir las herramientas de desarrollador.
Ve a la pestaña Network (Red) y en el filtro de búsqueda escribí m3u8 o mp4.
Dale play al video. Si aparece un archivo en la lista, hacé clic derecho sobre él, copiá su URL y usá el método de VLC o una página de descargas como hiciste antes.
3. Alternativa para celular (Android)
Si estás desde el celular, los navegadores comunes no te van a dejar. Tenés que usar un navegador con extractor integrado:
Descargá 1DM (1DM: Browser & Downloader) desde la Play Store.
Es un navegador que tiene un ícono de "antena/descarga" arriba. Entrás a la página del video, le das play, el ícono va a parpadear y te va a dejar descargar el archivo MP4 directamente a tu galería.

1. El trigger del Autoscroll (Tu especialidad)
En Joi, las salas de chat pesadas limitan el DOM drásticamente. Al igual que hiciste con ChatGPT, vas a necesitar que tu scroll.js inyectado detecte el contenedor principal (suele ser un div con clases de Tailwind de desborde vertical como overflow-y-auto) y tire un scroll top controlado. 2. Capturar el Payload en tu inject.js
A diferencia de OpenAI que te devuelve estructuras hiper-complejas con nodos internos de asignación de autores y mapas de mensajes editables (model_editable_context), Joi te va a escupir un JSON plano y hermoso por página.
Vas a tener que meter el hook en el window.fetch dentro de tu pipeline de captura:
javascript
// Dentro de tu lógica de captura de fetch en inject.js
if (url.includes('/api/chats') && url.includes('messages')) {
    const clone = response.clone();
    clone.json().then(payload => {
        // Joi suele devolver un array directo o un objeto { messages: [...] }
        const rawMessages = payload.messages || payload;
        
        window.postMessage({
            type: 'JOI_CHUNKS_CAPTURED',
            data: rawMessages
        }, '*');
    }).catch(() => {});
}
Usa el código con precaución.

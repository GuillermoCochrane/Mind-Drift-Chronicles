### 🧠 **Middleware global para integridad de originaciones vacías**
Este middleware podría interceptar ciertas rutas (o aplicarse solo a `POST /observacion`, `POST /pac`, `DELETE /observacion/:id`, etc.) y verificar:

1. Si una originación quedó sin observaciones ni PACs después de una eliminación.

#### 💡 Ejemplo conceptual:
```js
// middleware/checkOriginacionIntegrity.js
const { Originacion, Observacion, Pac } = require('../models');
module.exports = async (req, res, next) => {
  const { idOriginacion } = req.body; // o req.params, según el endpoint
  if (!idOriginacion) return next(); // si no hay originación, no aplica
  const originacion = await Originacion.findByPk(idOriginacion);
  if (!originacion) return next(); // ya no existe, o fue eliminada
  const observaciones = await Observacion.count({ where: { originacionId: idOriginacion } });
  const pacs = await Pac.count({ where: { originacionId: idOriginacion } });
  if (observaciones + pacs === 0) {
    await originacion.destroy(); // o marcar como eliminada si usás soft delete
    console.log(`Originación ${idOriginacion} eliminada por no contener registros.`);
  }
  next();
};
```

## 🤯 Por qué PHP se parece a EJS
Porque conceptualmente es lo mismo:

- EJS: HTML con JS embebido
- PHP: HTML con PHP embebido

Ejemplo mental:
EJS:
```ejs
<div><%= user.name %></div>
```
PHP:
```php
<div><?= $user['name'] ?></div>
```
Mismo patrón:
👉 template + lógica embebida.
O sea: tu intuición fue perfecta.
La diferencia es que en Node/EJS:
- la arquitectura suele estar separada (MVC)
- el backend está en otro lado

En PHP clásico:
- todo puede vivir en el mismo archivo 😈

     - En esta evidencia, se debe registrar la fecha en la que se realizó la acción y adjuntar cualquier prueba relevante que demuestre la correcta ejecución de la tarea.
   
### 2. **Rol Originador**
   - **Descripción**: Este rol permite a los usuarios identificar y registrar observaciones o desviaciones (denominadas PACs - Planes de Acción Correctiva) y asignarlas a los responsables de tratamiento.
   - **Acciones y funciones**:
     - Crear una nueva observación o PAC en la pestaña correspondiente, registrando todos los detalles del desvío, incluyendo:
       - Fecha y descripción detallada del desvío.
       - Locación, equipo o área afectada.
       - Documento donde se registró la observación (si aplica).
       - Persona y ente (por ejemplo, YPF) que detectaron el desvío.
     - Especificar el sector al que se asigna el desvío, con datos que se borrarán automáticamente si no se completa la creación de la PAC.
     - Cuando el desvío proviene de una inspección, indicar el número del inciso del formulario y detallar la fecha para corregir el desvío detectado.
     - Opcionalmente, añadir fotos o documentos adicionales que ayuden a entender mejor el desvío.
     - Asignar el responsable de tratamiento del desvío y permitir, si es necesario, que esta persona cambie la fecha de corrección.
     - Reabrir una observación o PAC previamente cerrada si al revisarla se considera que la corrección fue insuficiente o incorrecta.
### 3. **Rol Tratador**
   - **Descripción**: Este rol está enfocado en los usuarios responsables de analizar y tomar acciones correctivas sobre los desvíos o PACs.
   - **Acciones y funciones**:
     - Acceder a la lista de todas las PACs y observaciones asignadas para tratamiento.
     - Utilizar filtros para encontrar la PAC o la observación que se desea tratar.
     - Visualizar, exportar y editar cada PAC u observación según sea necesario.
     - **Análisis y tratamiento de PACs**:
       - Realizar un análisis de la causa raíz del desvío y documentar la acción tomada en respuesta al problema detectado.
       - Especificar y cargar las acciones o tareas necesarias para corregir el desvío.
       - Guardar los cambios en el formulario de tratamiento o finalizar el tratamiento cuando se hayan completado todas las acciones requeridas.
     - **Análisis y tratamiento de observaciones**:
       - De manera similar, cargar las acciones correctivas necesarias para cada observación registrada y guardar o finalizar el tratamiento según corresponda.
### 4. **Rol Observador**
   - **Descripción**: Este rol es para aquellos encargados de verificar la efectividad de las acciones tomadas para corregir el desvío.
   - **Acciones y funciones**:
     - Recibir una notificación o correo cuando el ejecutor ha completado una tarea asignada.
     - Revisar la evidencia de la acción tomada por el ejecutor para asegurar que sea la correcta.
     - Si considera que la acción fue adecuada, marcarla como "verificada y efectiva", lo cual cierra la PAC/observación como resuelta.
     - Si considera que la acción no es adecuada, marcar "no" y explicar la razón. Esta observación se marcará como "verificada no efectiva", indicando que el desvío no fue corregido adecuadamente y posiblemente requiera acciones adicionales.
### 5. **Indicadores y Reportes (Acceso para varios roles)**
   - **Histórico de PACs/Observaciones**: Permite acceder a un historial de todas las PACs y observaciones generadas en el sistema, con detalles específicos.
   - **Histórico de Acciones**: Brinda una vista detallada de todas las acciones realizadas, mostrando los responsables y la evolución de cada caso.
   - **Exportar información**: Es posible exportar los datos tanto de PACs/observaciones como de las acciones asociadas para análisis y seguimiento externo.
Este sistema organiza de manera clara cada rol y asegura la trazabilidad de todas las acciones realizadas para corregir desvíos, ayudando a mantener una alta calidad y cumplimiento en los procesos de la organización.

Sí, es posible conectar una aplicación desarrollada en Express con una plataforma Moodle mediante API. Moodle ofrece una API RESTful, que permite interactuar con sus funciones y datos. Aquí tienes algunos pasos y consideraciones para lograr esta conexión:

1. **Configuración de la API en Moodle**:
   - Primero, asegúrate de que la API de Moodle esté habilitada. Esto generalmente se hace en el área de administración de Moodle, donde puedes configurar servicios web y tokens de API.
   - Crea un token para la cuenta de usuario que representará a tu aplicación en Moodle. Esto permite a tu aplicación Express autenticarse en las solicitudes a la API de Moodle.

2. **Solicitudes API desde Express**:
   - Utiliza el token de autenticación generado para realizar solicitudes HTTP desde tu aplicación Express hacia la API REST de Moodle.
   - Moodle expone diversos endpoints para crear, leer, actualizar o eliminar datos, y cada acción en Moodle tiene un "función web" (nombre del endpoint). Por ejemplo, para crear un usuario, puedes usar el endpoint `core_user_create_users`.

3. **Implementación en Express**:
   - En tu aplicación Express, usa un paquete como `axios` o `node-fetch` para manejar las solicitudes HTTP a Moodle.
   - Puedes estructurar tu código de manera que cada función de interacción con Moodle esté representada en una ruta específica o un controlador que gestione las operaciones con Moodle.

4. **Seguridad y validaciones**:
   - Asegúrate de manejar los tokens de acceso con cuidado y aplica validaciones para asegurarte de que las respuestas de Moodle cumplan con tus requisitos antes de procesarlas.
   - Configura la comunicación mediante HTTPS para mantener segura la conexión entre tu aplicación y Moodle.

5. **Sincronización y manejo de errores**:
   - Si tu aplicación necesita sincronizar datos con Moodle, configura rutas que puedan escuchar los cambios necesarios y manejar errores o reintentos en caso de fallos de comunicación.
Con esta integración, tu aplicación Express podrá interactuar directamente con Moodle para realizar tareas como gestionar usuarios, asignar roles, recuperar datos de cursos, etc., lo cual es ideal para aplicaciones de aprendizaje o gestión de usuarios.
